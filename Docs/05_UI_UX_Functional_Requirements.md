# المتطلبات الوظيفية لواجهة وتجربة المستخدم (UI/UX Functional Requirements)
**الإصدار:** 1.0 (تصميم موجه لسرعة التفاعل وتجربة الصفحة الواحدة)  
**تاريخ التحديث:** أكتوبر 2026  

---

## 1. فلسفة التصميم والهوية البصرية (Design Philosophy)
- **البساطة والوضوح العالي:** واجهة نظيفة خالية من أي شاشات أو خطوات تشتت انتباه المستخدم أثناء وجوده في السوبرماركت أو الصيدلية.
- **نهج الأجهزة الذكية أولاً (Mobile-First):** تم تحسين كامل الواجهة لتعمل بسلاسة فائقة بإصبع الإبهام على الشاشات الرأسية الصغيرة (360px - 430px) مع التوسع الأنيق على شاشات التابلت وسطح المكتب.
- **التوافق التام مع اللغة العربية (RTL Native):** اتجاه قراءة طبيعي من اليمين إلى اليسار، وخط عربي حديث وواضح جداً للقراءة السريعة (مثل: **Cairo** أو **Tajawal**).

## 2. لوحة الألوان والرموز (Color Palette & Tokens)

| الاستخدام | الرمز اللوني (Hex / Variable) | الدلالة النفسية والوظيفية |
|---|---|---|
| **اللون الأساسي (Primary)** | `#0D9488` (Teal / فيروزي وقاية) | يبعث على الأمان الصحي والموثوقية والهدوء. |
| **خطر التكسير (Hemolysis Danger)** | `#EF4444` (Coral Red) | تحذير فوري وواضح من حدوث نوبة تكسير. |
| **الأمان الطبيعي (Safe Green)** | `#10B981` (Emerald Green) | طمأنة وتأكيد خلو المنتج من المشاكل. |
| **الخلفية الأساسية (Background)** | `#F8FAFC` (Slate Ultra Light) | خلفية مريحة جداً للعين تحت إضاءة المتاجر. |
| **خلفية البطاقات (Card Surface)** | `#FFFFFF` (Pure White) | بطاقات واضحة ذات ظلال ناعمة (Soft Elevation). |
| **النصوص الأساسية (Text Dark)** | `#0F172A` (Slate 900) | تباين عالٍ للقراءة تحت أشعة الشمس. |

## 3. تفاصيل مكونات الصفحة الرئيسية (Single-Page Layout)

### 3.1 الشريط العلوي (App Header)
- **الجانب الأيمن (RTL):** شعار وقاية الأخضر الفيروزي مع أيقونة درع ورمز G6PD، بجانبه نص الشعار: «وقاية - دليلك الآمن».
- **الجانب الأيسر (RTL):**
  - زر الإضافة: **`➕ أضف أكلة أو دواء`** (زر بارز بلون ممتلئ، يفتح نافذة الإضافة).
  - حالة المستخدم:
    - **غير مسجل (Guest):** زر `تسجيل الدخول / حساب جديد`.
    - **مسجل (Logged in):** اسم المستخدم مع شارة طبيب `🩺 طبيب` (إذا كان `is_doctor = true`) وقائمة منسدلة صغيرة لتسجيل الخروج.

---

### 3.2 شريط البحث والتصفية الفورية (Instant Search Bar)
- **حقل الإدخال:** شريط بحث عريض بتصميم عائم (Floating Bar) مع أيقونة بحث، ونص توضيحي (Placeholder):  
  *«ابحث باسم المنتج المصري.. مثال: لانشون، ريفو، كتاكيتو، فلافل»*
- **زر الحذف (Clear Button):** يظهر زر `✕` لمسح البحث بنقرة واحدة عند كتابة أي حرف.
- **كبسولات التصفية (Category Filter Chips):**
  - `الكل 🌐` (افتراضي)
  - `أكلات وسناكس 🍔`
  - `أدوية وصيدلية 💊`
  - التغيير فوري وتصفية القائمة بدون أي تأخير (Zero Lag).

---

### 3.3 بطاقة الصنف التفاعلية (Interactive Item Card)

```text
┌────────────────────────────────────────────────────────┐
│ [🍔 أكل]                                      14 صوّتوا │
│                                                        │
│  لانشون حلواني بقري سادة                               │
│  (بدون بروتين فول صويا مضاف)                           │
│                                                        │
│  ┌─────────────────────────┬────────────────────────┐  │
│  │ 🔴 تكسير: 8% (1 صوت)    │ 🟢 آمن: 92% (13 صوت)   │  │
│  └─────────────────────────┴────────────────────────┘  │
│                                                        │
│  [ ⚠️ حصل تكسير ]               [ ✅ آمن معي ]          │
└────────────────────────────────────────────────────────┘
```

1. **الترويسة:** شارة الفئة (Badge) على اليمين مع إجمالي المصوتين على اليسار.
2. **الاسم التجاري:** عنوان عريض بخط 18px Bold سهل القراءة.
3. **شريط الأمان المزدوج (Dual-Color Progress Bar):**
   - شريط أفقي بارتفاع 12px مقسم بنسبتي الأصوات:
     - جزء أحمر يمثل `% التكسير`.
     - جزء أخضر يمثل `% الأمان`.
   - فوق الشريط أو عند لمسه يظهر نص رقمي واضح: `8% حصل تكسير | 92% آمن`.
   - في حال كان الصنف جديداً تماماً دون أصوات، يظهر شريط رمادي محايد مع نص: *«كن أول من يصوّت على هذا الصنف»*.
4. **زرا التصويت السريع (Action Buttons):**
   - زر التكسير: `[ حصل تكسير ⚠️ ]` بخلفية حمراء فاتحة وحد أحمر.
   - زر الأمان: `[ آمن معي ✅ ]` بخلفية خضراء فاتحة وحد أخضر.
   - **التأثير البصري:** عند ضغط المستخدم المسجل، يتم تلوين الزر المختار باللون الكامل (Solid Fill) فوراً ويتحدث الشريط محلياً (Optimistic UI).

## 4. النوافذ المنبثقة التفاعلية (Modals & Dialogs)

### 4.1 نافذة التصويت السريع للزائر (Quick 10-Second Auth Modal)
- **محفز الظهور:** عندما يضغط زائر غير مسجل على أحد زري التصويت.
- **التصميم:**
  - رسالة تشجيعية دافئة: *«صوتك يحمي غيرك! سجّل في ١٠ ثوانٍ لحفظ تجربتك»*.
  - إمكانية التبديل بين **«إنشاء حساب سريع»** و **«تسجيل الدخول»** بتبويب واحد.
  - حقول الإدخال:
    - الاسم (في التسجيل).
    - البريد الإلكتروني أو رقم الهاتف.
    - كلمة المرور.
    - خيار بسيط: `[ ] أنا طبيب أو صيدلي`.
  - **ميزة الإكمال التلقائي الذكي:** بمجرد نجاح تسجيل الدخول، يتم تنفيذ الصوت الذي ضغط عليه الزائر تلقائياً وتغلق النافذة وتظهر رسالة نجاح خضراء (Toast Notification).

---

### 4.2 نافذة إضافة صنف جديد (Add Item Modal)
- **الحقول:**
  1. **اسم الصنف في السوق:** (حقل نصي إجباري) - مثال: "بسكويت أولكر بالتمر".
  2. **نوع الصنف:** زران كبيران للاختيار بنقرة واحدة:
     - `[ 🍔 أكل أو مشروب ]`
     - `[ 💊 دواء أو مكمل ]`
  3. **صورة المنتج (اختياري):** زر كاميرا بسيط لالتقاط أو رفع صورة غلاف الصنف.
  4. **صوتك الشخصي المبدئي:**
     - خيار فوري: `[ هل سبب تكسيراً معك؟ نعم ⚠️ / لا، آمن ✅ ]`.
- **زر الحفظ:** `نشر الصنف فوراً 🚀`، يضاف الصنف أعلى القائمة لحظياً.

## 5. الحركات والتأثيرات اللحظية (Micro-Interactions)
- **Ripple Effect:** اهتزاز خفيف وتأثير بصري عند الضغط على أزرار التصويت.
- **Smooth Transition:** انسيابية حركة الشريط المزدوج عند تغير النسب المئوية.
- **Skeleton Loading:** بطاقات رمادية نابضة خفيفة أثناء تحميل أول دفعة من البيانات لمنع الشاشة البيضاء.
